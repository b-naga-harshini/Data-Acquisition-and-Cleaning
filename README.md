# Supply Chain Data Acquisition and Cleaning

## Project Overview

This project focuses on acquiring, profiling, cleaning, and preparing a Supply Chain dataset for data analysis.

## Objectives

- Perform data acquisition
- Profile the dataset
- Identify missing values
- Detect duplicate records
- Detect outliers using the IQR method
- Standardize categorical data
- Encode categorical variables
- Normalize numerical variables
- Perform feature engineering
- Export the cleaned dataset

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Jupyter Notebook

## Dataset

The dataset contains supply chain information such as:

- Product Type
- SKU
- Price
- Availability
- Number of Products Sold
- Revenue Generated
- Stock Levels
- Lead Times
- Order Quantities
- Shipping Times
- Shipping Costs
- Supplier Name
- Manufacturing Costs
- Defect Rates
- Transportation Modes
- Routes

## Data Cleaning Process

1. Data Loading
2. Data Profiling
3. Missing Value Handling
4. Duplicate Detection and Removal
5. Outlier Detection
6. Data Standardization
7. Categorical Encoding
8. Numerical Normalization
9. Feature Engineering
10. Final Validation
